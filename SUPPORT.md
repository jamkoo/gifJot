# GifJot Support

Start at [gifjot.com](https://gifjot.com) for the current download and product
overview.

## Before opening an issue

- Install the [latest release](https://github.com/jamkoo/gifJot/releases/latest).
- Restart GifJot after changing Screen Recording permission.
- Confirm that your Mac is running macOS 14 or later.
- The primary public-beta platform is Apple silicon. Intel users are welcome to
  help with compatibility testing; include the Mac model in any report.
- Reproduce the problem using non-sensitive content.

## Bug reports

Open a [bug report](https://github.com/jamkoo/gifJot/issues/new?template=bug_report.yml)
with the GifJot version, macOS version, Mac architecture, steps to reproduce,
expected result, and actual result.

Never upload private recordings, credentials, personal paths, or sensitive
logs. Use [private vulnerability reporting](SECURITY.md) for security or privacy
problems.

## Feature requests

Open a [feature request](https://github.com/jamkoo/gifJot/issues/new?template=feature_request.yml)
and describe the workflow problem rather than prescribing an implementation.

For a question that does not belong in a public issue, email
[hi@gifjot.com](mailto:hi@gifjot.com). Never send private recordings,
credentials, personal paths, or sensitive logs.

The source code is private, and this repository does not accept code
contributions.
